Using the API

No API key or sign-up is required. Fetch JSON directly from this site. Catalogs are cumulative: a generation includes resources introduced by that generation, rather than guaranteeing availability in every game.

Check each index’s schema version before consuming records. Historical fields can be unavailable or backfilled; consult the data contract for field semantics and limitations.
